# Tone Dial v1: plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App de desktop nativo para Linux que grava do microfone ou abre um áudio existente e gera um `.md` com a transcrição em pt-BR separada por falantes, tudo local.

**Architecture:** Um crate Rust só, com um binário de janela (`tonedial`, egui) e um binário de linha de comando de desenvolvimento (`tonedial-cli`), os dois em cima da mesma biblioteca. A biblioteca tem uma pipeline (decodificar com ffmpeg → transcrever com whisper.cpp → separar falantes → alinhar palavras com falantes → escrever `.md`) que roda numa thread e manda progresso por canal. A UI é uma máquina de estados (Setup, Ocioso, Gravando, Processando, Pronto, Erro).

**Tech Stack:** Rust (edition 2024, rustc 1.98), eframe/egui, whisper-rs 0.16 (feature `vulkan`), speakrs (plano B: sherpa-onnx), cpal, hound, ffmpeg/ffprobe do sistema, ureq, serde/serde_json, dirs, chrono, rfd, open, anyhow.

**Spec:** `docs/superpowers/specs/2026-10-28-tonedial-v1-design.md`

## Global Constraints

- Só Linux (Fedora KDE) na v1. Nada de Electron ou webview.
- Tudo local. A rede só é usada para baixar os modelos na primeira execução.
- Idioma da transcrição fixo em `pt`.
- Backend do whisper.cpp: **Vulkan** (feature `vulkan` do whisper-rs), não CUDA.
- Modelo: `ggml-large-v3` em q8_0, quantizado localmente a partir do f16 oficial. Fallback: `ggml-large-v3-q5_0.bin` oficial (decidido na Task 6).
- Transcrição e diarização rodam em sequência, nunca ao mesmo tempo, para não disputar a VRAM.
- Faltar VRAM ou GPU cai para CPU sozinho, com aviso na tela.
- Saída: `AAAA-MM-DD-HHMM.md`, com `-2`, `-3`... se já existir. Fala no formato `**Falante N** [HH:MM:SS]: texto`, uma por parágrafo, numerada pela ordem da primeira aparição.
- Áudio gravado: salvo como `.ogg` (Opus, 64 kbps, mono) com o mesmo nome do `.md`. O processamento usa o WAV original. Arquivo aberto do celular nunca é copiado nem movido.
- Modelos em `~/.local/share/tonedial/models` (via `dirs::data_dir()`), config em `~/.config/tonedial/config.json` (via `dirs::config_dir()`).
- Textos de interface em pt-BR. Identificadores de código em inglês.
- Um áudio por vez.

## Review Focus

1. **ffmpeg/ffprobe ausente:** mensagem clara "ffmpeg não encontrado, instale com `sudo dnf install ffmpeg`", sem panic. Teste na Task 3.
2. **Silêncio ou ruído longo** (celular esquecido gravando, ar-condicionado): sem frases inventadas repetidas em loop. O dedupe de repetições tem teste na Task 1, e o VAD fica ligado na Task 4.
3. **Pasta de saída apagada ou sem permissão:** erro claro na tela e o usuário pode escolher outra, sem perder o áudio gravado. Teste na Task 2 (`unique_output_stem` em pasta inexistente retorna erro) e Task 8 (o WAV temporário fica onde dá para escrever).
4. **Mic desconectado no meio da gravação:** a gravação para e o que já foi capturado é finalizado como WAV válido e processado. Teste na Task 8 (`WavSink` finalizado depois de erro produz WAV legível).
5. **GPU sem memória ou Vulkan indisponível:** cai para CPU e segue. Teste na Task 4 (`load_model` com `prefer_gpu` falhando tenta CPU), via injeção da função de carga.

### Task 1: Scaffold e núcleo da transcrição (alinhar, agrupar, dedupe, markdown)

**Files:**
- Create: `Cargo.toml`, `src/lib.rs`, `src/transcript.rs`, `src/main.rs` (só `fn main() {}` por enquanto)
- Test: `src/transcript.rs` (módulo `#[cfg(test)]`)

**Interfaces:**
- Produces:
  ```rust
  pub struct Word { pub start_ms: u64, pub end_ms: u64, pub text: String }        // text inclui o espaço inicial do token whisper, se houver
  pub struct SpeakerSegment { pub start_ms: u64, pub end_ms: u64, pub speaker: u32 } // speaker = id cru do diarizador
  pub struct Utterance { pub speaker: u32, pub start_ms: u64, pub text: String }    // speaker já renumerado 1..N
  pub struct Header { pub recorded_at: chrono::NaiveDateTime, pub duration_ms: u64, pub source_name: String }
  pub fn dedupe_repeats(words: Vec<Word>) -> Vec<Word>
  pub fn align(words: &[Word], segments: &[SpeakerSegment]) -> Vec<Utterance>
  pub fn render_markdown(header: &Header, utterances: &[Utterance]) -> String
  pub fn format_ts(ms: u64) -> String   // "HH:MM:SS"
  ```

Regras de `align`: cada palavra vai para o segmento com maior sobreposição de tempo (empate: o que começa primeiro). Sem sobreposição, vai para o segmento mais próximo. Sem nenhum segmento, tudo vira falante 1. Palavras seguidas do mesmo falante viram uma `Utterance` só, com `start_ms` da primeira palavra e o texto concatenado com `trim()` no final. Os ids crus são renumerados 1..N pela ordem da primeira aparição.

Regras de `dedupe_repeats`: se um n-grama de 1 a 8 palavras (comparando por texto normalizado: minúsculas, sem pontuação) se repete mais de 3 vezes seguidas, mantém só a primeira ocorrência.

Formato de `render_markdown`:
```
# Transcrição 2026-10-28 14:30

- Duração: 1h52min
- Áudio: reuniao.m4a

**Falante 1** [00:00:03]: Bom dia, pessoal.

**Falante 2** [00:00:07]: Bom dia.
```
Duração com menos de 1h: `52min`. Texto termina com `\n`.

- [ ] **Step 1: `cargo init --name tonedial`**, edition 2024, adicionar `chrono` e `anyhow`. Escrever os testes que falham (nomes e asserções), com helpers `word(start, end, text)` e `seg(start, end, speaker)`:
- `align_assigns_by_max_overlap`: palavra em [1000,2000], segmentos A=[0,1200] e B=[1100,2500] → vai para B.
- `align_renumbers_by_first_appearance`: ids crus 7, 3, 7 → falantes 1, 2, 1.
- `align_merges_consecutive_same_speaker`: 3 palavras do mesmo falante → 1 `Utterance` com `text == "a b c"`.
- `align_without_segments_is_speaker_1`: `segments` vazio → todas no falante 1.
- `align_word_in_gap_goes_to_nearest`: palavra em [3000,3100], segmentos [0,1000] e [3500,4000] → falante do segundo.
- `dedupe_collapses_loop`: `" obrigado"` repetido 20 vezes → 1. `"a b c"` repetido 6 vezes → `"a b c"`. `"sim sim"` (2 vezes) fica intacto.
- `format_ts_pads`: `format_ts(3_723_000) == "01:02:03"`, `format_ts(0) == "00:00:00"`.
- `render_markdown_matches_format`: igual, byte a byte, ao bloco de exemplo acima (duração 6_720_000 ms → `1h52min`).
